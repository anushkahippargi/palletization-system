# Palletization System

## Overview

This project implements a C++ palletization engine for generating robot-friendly box placement coordinates.

The project is being developed as part of an internship.

## Goals

- Compute pallet layouts
- Generate placement coordinates
- Generate packing statistics
- Support multiple palletization algorithms

## Planned Algorithms

- Rows
- Rows + Columns
- Wheel
- Wheel with Inner Fill

## Technologies

- C++
- CMake
- VS Code
- Git
